# School Page for Independence Day

In Barranquilla, Colombia, there is a holiday called "Batalla de boyacá" which was a national battle made for our rights and freedom. This page was a request for a School to made a simple page in memory of that day and with the collaboration of the school students.

## Information

Made with NextJS and typescript using YouTube-embedded videos.
